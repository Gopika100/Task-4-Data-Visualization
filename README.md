# Task 4 – Data Visualization and Dashboard

## 📊 Project Title
**Supermart Grocery Sales – Retail Analytics Dashboard**

## 📌 Project Overview

This project focuses on analyzing and visualizing a Supermart Grocery Sales dataset using **Tableau Public**.

The objective is to transform raw sales data into meaningful visualizations and an interactive dashboard that helps understand sales performance, profitability, orders, categories, sub-categories, regions, and monthly trends.

## 🛠️ Tools Used

- Tableau Public
- Microsoft Excel / CSV Dataset
- GitHub
- PowerPoint

## 📂 Dataset

The project uses the **Supermart Grocery Sales – Retail Analytics Dataset**.

The dataset contains information such as:

- Order Date
- Order ID
- Customer Name
- Category
- Sub Category
- City
- State
- Region
- Discount
- Sales
- Profit

## 📈 Visualizations Created

The following visualizations were created in Tableau:

1. **Total Sales**
2. **Total Profit**
3. **Total Orders**
4. **Monthly Sales Trend**
5. **Sales by Category**
6. **Profit by Category**
7. **Top 10 Sub-Categories by Sales**
8. **Sales by Region**

## 📊 Dashboard

An interactive dashboard titled:

**Supermart Grocery Sales Dashboard**

was created to provide a quick overview of the business performance.

The dashboard helps identify:

- Overall sales performance
- Total profit
- Number of orders
- Monthly sales trends
- Best-performing categories
- Profitability by category
- Top-selling sub-categories
- Regional sales performance

## 🔍 Key Insights

- Total Sales: **14,956,982**
- Total Profit: **3,747,121**
- Total Orders: **9,994**
- Sales performance was analyzed across different months.
- Category and sub-category performance were compared.
- Regional sales were analyzed to identify stronger-performing regions.
